# 👑 Royal Time - Complete Production Deployment Guide (100% Free, No Credit Card)

This guide walks you step-by-step through deploying the **Royal Time** backend and frontend for **FREE** on **Render.com** or **Railway.app** directly from your phone, tablet, or PC without needing a credit card!

---

## 🚀 Option 1: Deploy on Render.com (Recommended Free Method)

Render offers a generous **Free Web Service** tier that runs Node.js applications with zero credit card required.

### Step 1: Push Code to GitHub
1. Create a free account at [github.com](https://github.com) if you don't already have one.
2. Create a new repository named `royal-time-app` (public or private).
3. Upload or push all project files (`server.js`, `package.json`, `index.html`, `addddmin.html`, `earn.html`, `refer.html`, `withdraw.html`, `activate.html`, `profile.html`, `royal-chain.html`, `royal-core.js`, etc.) to your repository.

### Step 2: Sign Up on Render.com
1. Open [render.com](https://render.com) on your browser (works on mobile too).
2. Click **Get Started for Free** and choose **Sign in with GitHub**. (No credit card asked).

### Step 3: Create a New Web Service
1. In the Render Dashboard, click **New +** > **Web Service**.
2. Select **Build and deploy from a Git repository**.
3. Connect your `royal-time-app` repository.
4. Fill in the service configuration:
   - **Name**: `royal-time-backend` (or any name you like)
   - **Region**: Choose closest to your audience (e.g. *Singapore* or *Frankfurt*)
   - **Branch**: `main`
   - **Runtime**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Instance Type**: Select **Free** ($0/month)

### Step 4: Configure Environment Variables
Scroll down to the **Environment Variables** section and add the following keys:

| Key | Example Value | Description |
|---|---|---|
| `PORT` | `3000` | Render automatically binds this |
| `NODE_ENV` | `production` | Enables production caching |
| `BOT_TOKEN` | `7123456789:AAH...` | Your Telegram Bot Token from [@BotFather](https://t.me/BotFather) |
| `BOT_USERNAME` | `RoyalTimee_Bot` | Your Telegram Bot Username without `@` |
| `JWT_SECRET` | `royal_jwt_ultra_secret_key_998877` | Any long random secret string |
| `ADMIN_SECRET_KEY`| `royal_master_admin_secret_998877` | Secret key for logging into admin |
| `ADMIN_PIN` | `778899` | Master PIN for `addddmin.html` |
| `FIREBASE_PROJECT_ID` | `rc-project-a83cf` | Your Firebase Project ID |
| `FIREBASE_CLIENT_EMAIL` | `firebase-adminsdk-xxx@...` | From Firebase Service Account Key |
| `FIREBASE_PRIVATE_KEY` | `-----BEGIN PRIVATE KEY-----\n...` | Your private key (preserve `\n`) |
| `IMGBB_API_KEY` | `61c1689422ba034a86e3cdc80153165e` | For screenshots & proofs upload |

*(Tip: In Firebase Console > Project Settings > Service Accounts > "Generate New Private Key", download the JSON and copy `client_email` and `private_key`)*.

### Step 5: Deploy & Get Your Live URL
1. Click **Create Web Service**.
2. Render will build and launch your application in ~1-2 minutes.
3. You will get a live HTTPS URL like:
   `https://royal-time-backend.onrender.com`
4. Test it by opening `https://your-app.onrender.com/api/health` in your browser. It will reply with `{"status":"ok"}`.

### Step 6: Link to Telegram Bot (@BotFather)
1. Open [@BotFather](https://t.me/BotFather) on Telegram.
2. Send `/mybots` > select your bot.
3. Choose **Bot Settings** > **Menu Button** > **Configure menu button**.
4. Send your Render Web App URL: `https://your-app.onrender.com`.
5. Also run `/setmenubutton` or set up Telegram Web App inline links:
   `https://t.me/RoyalTimee_Bot/app`

## 🚅 Option 2: Deploy on Railway.app

1. Go to [railway.app](https://railway.app) and sign in with GitHub.
2. Click **New Project** > **Deploy from GitHub repo** > select `royal-time-app`.
3. In **Variables**, add the exact same environment variables listed in the table above.
4. In **Settings** > **Networking**, click **Generate Domain** to get your public HTTPS URL.
5. Railway automatically runs `node server.js` from `package.json`!

## 🔒 Security Hardening Checklist

- [x] **Zero Client-Side Balance Tampering**: Balance updates, loan repayments, and referral rewards execute exclusively through atomic backend transactions.
- [x] **Telegram HMAC Authentication**: Official HMAC-SHA256 signature verification guarantees users can only authenticate with authentic Telegram sessions.
- [x] **Protected Admin Console**: Hardcoded PIN in HTML removed. Admin console is authenticated via signed JWT token generated by `/api/admin/login`.
- [x] **Dedicated Promo Code Manager**: Create codes with RC amount, max user count, expiry date, toggle active/disabled, and atomic usage tracking.
- [x] **Anti-Cheat Ad Gate**: Strict cooldowns & session tracking prevent rapid automated bot requests.
